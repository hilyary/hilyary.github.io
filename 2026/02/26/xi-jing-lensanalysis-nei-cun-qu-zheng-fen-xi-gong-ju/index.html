前言

今天给大家介绍一款专业的内存取证分析工具——析镜 LensAnalysis，它基于 Volatility 3 框架开发，为安全研究人员、CTF 爱好者和应急响应人员提供强大的内存镜像分析能力。

功能特性

跨平台支持

平台支持情况
Windows原生支持，提供 .exe 可执行文件
macOS提供 .dmg 安装包
Linux暂不提供（无用户需求）

注意：Windows 版本由于是 py 打包，没有签名可能会误报有毒，请放心使用。

强大的分析能力

Windows 内存镜像

分类支持的分析功能
进程分析pslist, pstree, psscan, dlllist, handles, cmdline
网络分析netscan, netstat（含完整时间戳）
注册表hivelist, printkey, certificates, userassist
恶意代码malfind, ldrmodules, hollowprocesses
密码提取hashdump, lsadump, cachedump
服务扫描svcscan, svclist
更多60+ Windows 分析插件

Linux 内存镜像

分类支持的分析功能
进程分析pslist, pstree, psaux, envars
网络分析netstat, sockstat, ip_addr, ip_link
内核模块lsmod, check_modules, check_syscall
Bash 历史bash 命令历史提取
文件系统lsof, list_files, mount_info
恶意代码malfind, check_idt, check_afinfo

macOS 内存镜像

分类支持的分析功能
进程分析pslist, pstree, psaux, envars
网络分析netstat, ifconfig
内核扩展lsmod
文件系统lsof, list_files, mount
系统信息timers, kauth_listeners, vfsevents

CTF 专用功能

对于 CTF 玩家来说，以下功能非常实用：

  • Flag 搜索 - 自动搜索常见 Flag 格式（flag{xxx}）
  • 正则搜索 - 自定义正则表达式搜索内存
  • 字符串提取 - 提取所有可打印字符串

性能优化

  • 智能缓存 - 分析结果自动缓存，重复操作秒级响应
  • 符号表管理 - 自动下载和管理系统符号表
  • 代理支持 - 支持 HTTP/HTTPS/SOCKS5 代理

特色功能

Linux 符号表自动制作 - 从官方源自动下载 dbgsym 调试符号包并转换为 Volatility 3 所需的 ISF 格式符号表。支持 Ubuntu、Debian、CentOS 等发行版，无需手动寻找和制作符号表。

报告导出

支持多种格式的报告导出：

  • Markdown - 生成 Markdown 格式报告
  • HTML - 生成网页格式报告
  • Word - 生成 Word 文档报告

下载安装

Windows

  1. 下载 LensAnalysis1.0.0.exe
  2. 核对 MD5 值：434e132480e84c9f9e70322f9c1e65f5
  3. 双击运行即可
  4. 首次运行需要激活（激活码免费）

macOS

  1. 下载 LensAnalysis.dmg
  2. 核对 MD5 值：4c623e94ad916228e437211e7472db22
  3. 打开 DMG 文件
  4. 将 LensAnalysis.app 拖到 Applications 文件夹
  5. 打开应用（首次运行需要右键→打开）

快速上手

1. 启动应用

  • Windows: 双击 LensAnalysis.exe
  • macOS: 启动台打开 LensAnalysis

2. 加载镜像

  • 点击「加载镜像」按钮
  • 选择内存镜像文件（.raw、.mem、.vmem 等）
  • 选择操作系统类型（可选，系统会自动检测）

3. 执行分析

  • 左侧面板选择分析插件
  • 点击即可执行分析
  • 结果实时显示在右侧面板

4. 导出报告

  • 点击「导出报告」按钮
  • 选择报告格式（Markdown/HTML/Word）
  • 报告自动生成并保存
